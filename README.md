# کاو خرید — دستیار خرید حضوری Torob

اپ فارسی RTL با دادهٔ واقعی چالش، مقایسهٔ فروشنده، فهرست و برنامهٔ مراجعه؛ بدون کلید یا backend اجرا می‌شود.

- [اپ عمومی](https://pedrammgd.github.io/starcoach-torob-agent/)
- [دموی فارسی](https://pedrammgd.github.io/starcoach-torob-agent/video/)
- [سورس مستقل](https://github.com/pedrammgd/starcoach-torob-agent)

**این نسخه پس از ارسال لینک‌ها به‌روزرسانی شده است.** سه لینک ارسالی ثابت‌اند؛ نسخهٔ قبل در commit78eb480 و فیلم اولیه در همان تاریخچه محفوظ است. زمان و تغییرات در docs/release.json ثبت شده‌اند؛ ادعا نمی‌شود امکانات تازه در زمان ارسال اولیه وجود داشته‌اند.

## اجرا و بازتولید

Python3 کافی است؛ نصب بسته، کلید یا شبکه برای منطق اپ لازم نیست:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory docs
```

http://127.0.0.1:8772 را باز کنید. تصاویر cacheشده محلی‌اند؛ دیگر تصاویر از URLعمومی منبع و نقشهٔ خیابانی با کلیک کاربر ازOpenStreetMapمی‌آیند.

برای تولید دوبارهٔ JSON از CSVهای اصلی خودتان:

```sh
python3 scripts/import_dataset.py /path/to/starcoach-dataset-v16-cap300-csv
```

## مسیر قابل استفاده

جست‌وجوی نام/برند/دسته، بودجه با اعداد فارسی، مبدأ محله یا مختصات، شعاع هوایی و پذیرندگی حضوری اعلام‌شده → مقایسه با ترتیب قیمت یا فاصله و دلیل پیشنهاد → نقشهٔ مختصاتی واقعی → انتخاب یک فروشنده برای هر کالا → فهرست محلی، روز مراجعه و ترتیب نزدیک‌ترین همسایه.

تصاویر و مشخصات واقعی، تاریخ و ساعت کار خوانا، حالت خالی و بازیابی ورودی نامعتبر در رابط وجود دارند. تغییر فروشنده مبلغ همان کالا را دوبار حساب نمی‌کند. فهرست با بازکردن دوباره صفحه حفظ می‌شود و از offerواقعی بازسازی می‌شود.

«موجود/ناموجود» صرفاً **یادداشت شخصی کاربر** است؛ استعلام یا تأیید فروشنده نیست و به سرور ارسال نمی‌شود. انتخاب ناموجود از جمع و برنامه کنار می‌رود؛ فروشنده‌های دیگر همان کالا با پیشنهاد واقعی قابل انتخاب‌اند. یادداشت فروشندهٔ قبلی به فروشندهٔ جدید منتقل نمی‌شود. تعطیلی اعلام‌شده در روز مراجعه هشدار دارد؛ بازبودن زنده ادعا نمی‌شود.

## داده و صداقت

منبع واقعی:225903محصول،331506پیشنهاد و6476فروشگاه دارای مختصات معتبر. زیرمجموعهٔ UI:1800محصول،6035پیشنهاد،1304فروشگاه؛ انتخاب deterministicاز ترتیب منبع برای محصول دارای حداقل2فروشنده. SHA256هرسهCSV در DATASET_EVIDENCE.json ثبت شده است. هیچ ردیف مصنوعی اضافه نشده؛ بیشتر نام‌های فروشگاه در خود دیتاست رسمی مستعارند. شماره‌های جعلی، contacts، CSVخام و اطلاعات خصوصی منتشر نشده‌اند. عکس/مشخصات از همانproducts.csvآمده‌اند؛12عکس با منشأ وhashثبت‌شده cacheشده‌اند.

**قیمت تاریخی، زمان تغییر قیمت و موجودی تأییدشده متفاوت‌اند.** موجودی و قیمت امروز تضمین نیستند. پذیرندگی اعلامی، تضمین اعتبار یا پذیرش این کالا نیست. نتیجهٔ خالی در زیرمجموعه، نبودن کالا در کل ترب نیست. نقشه و برنامه بر اساس فاصله هوایی‌اند، نه مسیر خیابانی، ترافیک یا تضمین بهترین مسیر. ساعت کار، اعلامی است.

LLM، تماس/پیگیری خودکار فروشنده، رزرو و پرداخت فعال نیستند. قواعد انتخاب شفاف‌اند و AIمولد معرفی نمی‌شوند. چهار گام ویدئوی رسمی مستقلاً احراز نشده‌اند و ادعای مشاهدهٔ کامل آن نداریم. پوشش معیارهای300امتیازی درCHALLENGE_COVERAGE_FA.mdبدون تخمین امتیاز ثبت شده است.

## بررسی و دمو

UX_QA.json:21بررسی موفق مسیر واقعی باChromeو نمای موبایل390×844، بدون خطایJavaScript و بدون overflowصفحه در جست‌وجو/نقشه/برنامه. آزمون دستگاه فیزیکی ادعا نمی‌شود. اسکریپت scripts/verify_ux.cjsبه Node وPlaywright نیاز دارد؛ PLAYWRIGHT_MODULEمسیر نصب اختیاری و CHROME_PATHمسیرChromeاست.

ویدئوی جدید حدود5دقیقه،1920×1080،H264/AACو دارای **روایت فارسی مصنوعی** fa-IR-FaridNeuralاست. تصویر از تعامل واقعی اپ ضبط و برای خواندن با سرعت0.5تدوین شده؛ benchmarkسرعت نیست. متن عمومی پروژه به سرویس گفتار عمومیEdgeارسال شد؛ نه کلید، تماس، موقعیت شخصی یا یادداشت واقعی کاربر. کلید صورتحساب یا منبع پولی استفاده نشد. DEMO_QA.jsonمشخصات واقعی وdecodeکامل را ثبت می‌کند. فیلم اولیه در صفحه پخش قابل دریافت است.

ابزار اختیاری تولید ویدئو جدا از اپ: scripts/record_demo.cjs باPlaywright؛ scripts/narrate_demo.py --online باedge-tts؛ scripts/build_demo_video.py باFFmpeg. ضبط خام و صدای میانی درartifactsو خارجGitهستند. منبع Liara/Wallex و فرم مسابقه تغییر نکرده‌اند.
