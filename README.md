# کاو خرید — دستیار حضوری Torob

MVP فارسی RTL با دادهٔ واقعی رسمی چالش، قابل میزبانی کاملاً استاتیک. این پروژه تازه در این جلسه ساخته شد؛ نسخهٔ کامل قبلی در مسیر اعلام‌شده وجود نداشت.

## اجرا

Python3 کافی است؛ بدون کلید، نصب بسته یا backend:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory docs
```

http://127.0.0.1:8772 را باز کنید. برای import دوباره از فایل‌های اصلی خودتان:

```sh
python3 scripts/import_dataset.py /path/to/starcoach-dataset-v16-cap300-csv
```

## مسیر واقعی خرید

جست‌وجوی محصول و بودجه → مقایسهٔ قیمت‌های ثبت‌شده و فروشندگان → فاصله و نقشهٔ مختصاتی → انتخاب پیشنهاد → فهرست محلی و ترتیب مراجعهٔ نزدیک‌ترین همسایه. مبدأ مختصاتی قابل تغییر است؛ پیش‌فرض مرکز تهران است و موقعیت کاربر ادعا نمی‌شود. فهرست در localStorage همین مرورگر ذخیره می‌شود. هیچ تماس، رزرو یا خرید اجرا نمی‌شود.

## شواهد داده

فایل‌های اصلی واقعی:225903محصول،331506پیشنهاد و6476فروشگاه دارای مختصات معتبر. نمونهٔ عمومی:1800محصول دارای حداقل2فروشندهٔ متمایز،6035پیشنهاد و1304فروشگاه. انتخاب deterministic از ترتیب اصلی داده است؛ هیچ محصول یا قیمت ساختگی اضافه نشده است. SHA256هرسهCSV در DATASET_EVIDENCE.json ثبت شده. CSVهای اصلی و شمارهٔ تماس در Git نیستند. ستون‌های منتخب عمومی دادهٔ اپ در docs/data.json هستند.

قیمت‌ها **تاریخی** و موجودی **تأییدنشده** است؛ دستهٔ فروشگاه اثبات موجودی نیست. نام بیشتر فروشگاه‌ها در دیتاست رسمی مستعار و شماره‌ها جعلی‌اند؛ contacts اصلاً وارد اپ نشده است. زمان تغییر قیمت و ساعت کار اعلامی، تأیید زنده نیستند.

## محدودیت‌های صریح

چهار گام ویدئوی رسمی مستقلاً احراز نشده‌اند و ادعای مشاهدهٔ آن ویدئو نداریم. نقشه SVG از مختصات واقعی است؛ مسیریابی خیابانی/ترافیکی نیست. لینک OpenStreetMap هر فروشگاه واقعی است. پیشنهادها deterministic بر اساس قیمت و فاصله‌اند؛ LLM فعال نیست. تأیید موجودی، تماس با فروشنده، پیگیری خودکار، رزرو و پرداخت پیاده نشده‌اند. این MVP بدون دسترسی به اطلاعات موقعیت شخصی یا APIkey اجرا می‌شود.

## تحویل

صفحهٔ اپ در docs/index.html، صفحهٔ پخش در docs/video/index.html و MP4 در docs/video/demo.mp4 قرار می‌گیرد. ویدئو ضبط تعامل واقعی همین اپ است؛ بدون روایت صوتی و با توضیحات فارسی. داده یا عملکرد ساختگی در آن نیست. GitHubPages از main/docs می‌تواند اپ و ویدئو را بدون منبع پولی میزبانی کند. هیچ منبع Liara تغییر نکرده است.


## بازبینی UX

رابط چهار بخش مجزا، عکس/مشخصات واقعی محصول با fallback، مقایسه با دلیل قیمت/فاصله، بودجه با اعداد فارسی، محدوده هوایی، مبدأهای قابل تغییر و فیلتر «پذیرندگی حضوری اعلام‌شده» دارد. هر محصول فقط یک فروشنده در فهرست دارد؛ جایگزینی فروشنده جمع را دوبار حساب نمی‌کند. فهرست قدیمی از شناسهٔ واقعیofferمهاجرت می‌کند و storageخراب مانع شروع اپ نیست. ساعت کار هفتگی و روز مراجعه خوانا هستند و همچنان «اعلامی»اند. پیشنهاد هم‌دسته سازگاری فنی را تضمین نمی‌کند.

آزمون مرورگر موبایل در `scripts/verify_ux.cjs` و نتیجه در `UX_QA.json` است. با Node و Playwright نصب‌شده اجرا می‌شود؛ متغیر PLAYWRIGHT_MODULE مسیر نصب اختیاری آن و CHROME_PATH مسیر Chrome است. در محیط این پروژه آزمون با مرورگر موقت و بدون حساب انجام شد. تصاویر نمایشیِ در دسترس برای پایداری محلی cacheشدند؛ سایر تصاویر از URLواقعی منبع می‌آیند و خطای تصویر fallback دارد.

فیلم عمومی موجود، ضبط واقعی نسخهٔ نخست است و در صفحهٔ پخش همین موضوع اعلام شده است. تلاش بازضبط UXجدید نهایی نشد؛ فیلم تازه یا مشاهدهٔ کامل ویدئوی رسمی ادعا نمی‌شود. نسخه نخست در تاریخچهGit باقی است.
